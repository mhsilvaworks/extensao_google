Diagnóstico de Nave Estelar

Uma extensão para Google Chrome desenvolvida para o Bootcamp II materia da graduação de ciência da computação.

Visão Geral

Esta extensão simula um painel de diagnóstico de uma nave espacial, permitindo ao usuário verificar o status de vários sistemas críticos, como turbinas, escudos e suporte de vida. É um projeto focado em demonstrar as principais tecnologias do Manifest V3, incluindo Popups, Service Workers e Content Scripts.

Instalação

Para instalar a versão de desenvolvimento, siga os passos:

  1. Faça o download da versão mais recente clicando aqui.
  2. Descompacte o arquivo .zip em uma pasta no seu computador.
  3. Abra o Chrome e navegue até chrome://extensions.
  4. Ative o "Modo de Desenvolvedor" no canto superior direito.
  5. Clique em "Carregar sem compactação" e selecione a pasta que você descompactou.
